## 0. 一句话结论

老李全流程（分集→分镜→拼接→资产→投喂→机检）能完整落到本流水线，且用 EP1/EP2 真实交付稿 + 11 段人工稿 + 6 段真实提交稿做过回归，**全部 0 FAIL 0 WARN**。真正卡住的不是"能不能落"，而是三处**输入假设错了**：

1. 假设用户会把分镜表填完整（实际用户不会写道具名）→ 改为**原文层面自动建资产**；
2. 假设拼接完再建资产（实际要**边读边建边绑**）→ 改为流式三段合一；
3. 假设空间方位可以后期补（实际**blocking 必须由分镜阶段给**）→ 仍未闭环。
