## 二、P2-A：`set_scene_state` 的实际语义

| 项 | 实现 |
|---|---|
| 粒度 | 一章一次，`chapter` + `scenes[]`；`scenes[]` 每个元素 = 一个场次实例 |
| 唯一键 | `(project_id, scene_key)`；DDL 侧本就有 `uq_scene_state` 唯一索引兜底，应用侧先 SELECT 再 INSERT/UPDATE |
| 首次 | `INSERT`，`state_rev=1` |
| 重写 | `UPDATE`，`state_rev += 1`，**只更新本次显式给出的字段**（没给的保持原值——避免"改个轴锁把 fixtures 抹了"） |
| 批内重复 | 同一批里 `scene_key` 出现两次 → `SCENE_KEY_DUPLICATED`（否则一次提交会静默 +2 次 rev） |
| 越界写入 | 不写 `story_shots`、不写 `shot_actions`、不建资产（有专门用例断言三张表行数不变） |

写入的列：`scene_id` / `coord_system` / `fixtures` / `entries` / `axis_lock` / `power_geometry` / `crowd_switch` / `time_of_day` / `state_rev` / `updated_at`。

## 三、P2-B：允许"存在但未定义"，禁止"编造几何"

| 规则（§4.8.1） | 实现 | 测试 |
|---|---|---|
| 场次存在即可建行 | `scene_key` 只要求非空字符串，不要求任何几何字段 | SC-07（只有 `scene_key` + fixtures 也能建） |
| `coord_system` 缺 `basis`/`active_area` | **原样存 `{}`，不补默认值**；回包 `incomplete.coord_system=true` + `COORD_SYSTEM_INCOMPLETE`(info) | SC-05 同族断言（不补、只标记） |
| `axis_lock` 缺 `axis_line` | 允许落库，已确定字段保留；回包 `AXIS_LOCK_INCOMPLETE`(warn) + `AXIS_UNVERIFIED`(info, S-05/S-06) | **SC-05** |
| 不得从画面左右反推物理左右 | 程序侧不推导任何左右；缺 `axis_line` 就是缺（有注释与用例双重钉住） | SC-05（断言 `axis_line` 不被补出） |
| `fixtures[].zone` 约束 | 必须 4 个 `0..1` 数字且 `x1<x2`、`y1<y2`，否则 `FIXTURE_ZONE_INVALID` **整批回滚** | **SC-04**（三个数/越界/反向/非数字 五类） |
| `scene_id` 可为空 | 空串 = 虚拟场次，直接写空串 | **SC-07** |
| `scene_id` 非空须属本项目 + `category='scene'` | `SCENE_ASSET_NOT_FOUND`（带 foundProject/foundCategory 便于排错） | **SC-02** |
| `power_geometry` / `crowd_switch` 可空 | 不校验内容，缺就留空；不因缺而拒 | SC-01/SC-03 |
| **不得自动创建空场次基线** | `assertSceneKeysExist` 只做判定，**永不建行** | **SC-06**（行数不变） |

> §4.8.2 的 `SCENE_STATE_MISSING` 已作为**可调用判定**交付（`assertSceneKeysExist`），并有用例证明它不建行。把它接到 `set_storyboard`（抛错只拒该镜、同批其余镜继续）属 **P8**，本轮**未伪造端到端通过**。

## 四、P2-C：三层权限（描述不拦人，三层缺一不算闭合）

| 层 | 实现位置 | 证据 |
|---|---|---|
| **L1 看不到** | `openclaude-agent.js`：`SCRIPT_TOOL_NAMES`（12 个）+ `buildMcpTools` 的 `toolSet==='script'` 分支；**默认池改为 `TOOL_DEFINITIONS.filter(排除 SCRIPT_ONLY_TOOLS)`** | PS-01 / PS-02 |
| **L2 写不进** | `createToolRuntime({..., toolSet})` → `ctx.toolSet`（只由 `buildMcpTools` 构造时传入）；`hSetSceneState` **首行**断言 `ctx.toolSet === 'script'`，否则 `SCENE_STATE_WRITE_FORBIDDEN`，早于任何校验与落库 | PS-03 / PS-04 |
| **L3 夹带无效** | `set_scene_state` 的 schema **不声明 `stage`**；`runTool` 的 `ALLOWED_ARG_KEYS` 以 `unknown-args` 拦截 | PS-05（含 schema 结构性断言） |

三条实现细节值得记下来：

1. **默认池必须显式排除**，不能只加白名单分支。`buildMcpTools` 的缺省分支原本返回 `TOOL_DEFINITIONS` 全量，不改它 = 分镜创作阶段照样看得到并调得动（L2 会拒，但"看不到"这层就是空的）。
2. **`toolSet` 只从构造参数来**：不读 `args`、不读 `ctx.project.*`（后者用户可写，等于让客户端授权）。
3. **拒绝发生在首行**：PS-04 断言被拒后原有行的 `state_rev` 逐字不变——不是"写了再回滚"，而是根本没进入写路径。

| 提示词 | 单独两份（system + task），逐条压"不写镜 / 不编造几何 / 不得从画面左右反推" |
