# 打戏分镜 Skill（combat-storyboard）

把**打斗 / 武打 / 斗法 / 群战段落**写成可直投 Seedance 2.5 / 2.0 的分镜提示词。**文戏走 `storyboard-director`**，本 Skill 只负责动作层与编排层。

写打戏不是「描述一张图」，是「指挥一台有质量的摄影机、拍一场有完整物理因果的事件」——每个特效有材质和重量、每次发力有传导和回执、每镜有任务和机位、规模靠同框对比和持续证明。

## 一、三档路由（按戏种分派）

| 档位 | 子引擎 | 适用戏种 | 规则入口 |
|---|---|---|---|
| **R1 真人写实** | real | 现代格斗 / 警匪追逐 / 悬疑暗杀 / 喜剧打斗 / MMA / 群战（1v2/1v3） | `references/real/SKILL.md` |
| **R3 玄幻仙侠** | xuanhuan | 仙侠斗法 / 神魔大战 / 宗门对决 / 法武合一 / 大招终结 | `references/xuanhuan/SKILL.md` |
| **通用武侠** | combat | 武侠物理打斗 / 招式 / 剑阵 / 对轰 / 割草 / 法术对轰 | `references/combat/SKILL.md` |

**路由判定（按剧本戏种自动判，不询问）**：
- 现代写实、真实受力、**禁特效** → **R1 real**；
- 玄幻修仙、法宝术法、能量具象 → **R3 xuanhuan**；
- 通用武侠/高燃、物理招式 + 适度特效 → **combat**；
- 戏种未明时按剧本动作/特效词自动判定（出现法宝/法术/能量词 → R3；纯肉搏/警匪/MMA → R1；其余 → combat），禁止停下询问、禁止默认套错档。

## 二、前置锁（无人值守接口 · 锁由调用方传入，不询问）

本 Skill 面向**无人值守流水线**：锁的值由调用方（流水线项目锁卡）传入，**不询问用户、不弹卡、不停下等待**。缺失时按下表默认值兜底，不阻塞。

| 锁 | 键 | 来源 / 默认 | 说明 |
|---|---|---|---|
| A 模型版本 | `video_model` | 项目锁卡；`seedance25`=2.5 / `seedance20`=2.0 | 语法彻底分开，禁混写 |
| B 画幅 | `video_aspect_ratio` | 项目锁卡；16:9 / 9:16 / 21:9 | 全片唯一 |
| C 交付形态 | — | 流水线固定「md 投喂 + 成片」，不出离线看板 | 流水线上下文里不弹此锁 |
| D 段缝衔接 | `seam` | 项目锁卡；auto=按情绪节拍 / tail_frame=尾帧锚定 / hard_cut=换机位硬切 / empty_shot=空镜过渡 | 多段任务判定式不变 |
| I 画风锁 | `style` | 项目锁卡；真人实拍 / 2D 手绘 / 3D CG / 水墨二维 | 影像基底决定机位规则 |

> **无人值守铁律**：以上锁一律照流水线项目锁卡与项目记录落定；不存在「未指定即停下询问」——缺项用默认值，禁止中断等待用户。

**真人脸红线（R1 必读）**：Seedance 不支持上传含真人人脸的参考图/视频，角色参考图必须为动漫/CG/绘画风格；写实感靠「实拍影视质感/物理真实」提示词达成，不靠真人照片参考。

## 三、工作流（五步）

1. **读锁**：确认模型版本、画幅、戏种档位、战损累积、可用资产图。
2. **打斗构思**：先想清「为什么打、打向哪里」（动机/强弱错位/赌注/环境变数），再写「怎么拍」。
3. **八步写作**（combat 引擎铁律0）：八步链逐镜成句，输出全是自然分镜句（禁关键词袋、禁竖线串、禁字段罗列）。
4. **铁律自检**：逐镜过档位护栏（R1 真实受力 / R3 法武合一 / 通用 Hit-Stop）。
5. **投喂封装**：按 `references/shared/model-adapters.md` 七段式封装。

## 四、核心铁律（三档共通）

- **物理因果**：每次发力有传导和回执，禁「滑步」「空气假打」。
- **双向攻防**：力量互换，禁单向沙包。
- **时间轴整数秒**：`0-3秒`/`3-6秒`，禁小数点、毫秒、冒号时码、S01/S02 场次嵌套。
- **2.5/2.0 语法分开**：Hit-Stop、顿挫词、首尾帧、单段时长（30s/15s）按 `model-adapters.md` 对照表执行。
- **输出自然句**：禁关键词袋、竖线串、字段罗列；字段只存在于脑内。
- **资产编号沿用「图N」**：角色参考图零外观描述，省 token 给特效。
- **机检**：`scripts/validate_prompt.py`（C1~C26 + 打戏 C21 激烈度硬护栏 + C30 档位指纹探针，`--combat on|off|auto`）。

## 六、能力边界

- 本 Skill 只做**打戏分镜**：文戏分镜走 `storyboard-director`；剧本创作、资产锁定、成片质检、离线看板不在本 Skill 范围。
- references 内部偶引用的 `sd-*` 路径（如 `sd-script-engine`、`sd-decision-engine`）为**历史溯源痕迹**，对应规则要点已在正文说明，剧本/决策/资产能力不随本 Skill 提供。
- 本 Skill 不持有图、不出图；资产图由用户在外部平台生成（或走 `z-image-prompt-writing` 生图）。
