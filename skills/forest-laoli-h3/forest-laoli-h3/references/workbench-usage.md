# MiniMax H3 工作台使用方案（运行环境实操 · 2026-11-19 检索整理）

> 定位：本 skill 的产出是"平台无关的纯文本载荷 + 投喂包"，但用户最终要在某个 H3 运行环境里投喂。本文记录三个主流运行环境的关键差异与操作要点，避免投喂时因"素材代号写法 / 模式互斥 / 分辨率档位"翻车。

## 一、三个运行环境对比

| 维度 | 海螺 Web 工作台 | 本地 ComfyUI | MiniMax API |
|---|---|---|---|
| 入口 | hailuoai.video | ComfyUI 节点 `MiniMaxH3ReferenceToVideo` | platform.minimax.io |
| 素材引用写法 | `@Image1` / `@Video1` / `@Audio1` | `Image 1` / `Video 1` / `Audio 1` | `reference image 1`（文字描述） |
| 参考数上限 | 12 文件（9 图 + 3 视频 + 3 音频） | 同上 | 同上 |
| 分辨率 | 768P 试稿 → 2K 成片 | 768P（2K 需再走生成模块） | 768P / 2K |
| 时长 | 5–15s | 4–15s | 4–15s |

**本 skill 的六段式用 `<Picture N>` / `<Audio N>` 标签**，这是 Ref2VA 官方标签格式，在 ComfyUI 节点和 API 下直接适用；**若在海螺 Web 工作台跑，需把 `<Picture N>` 转成 `@ImageN` 风格**。投喂前先确认运行环境。

## 二、模式选择（关键：互斥）

| 模式 | 输入 | 用哪个 checkpoint |
|---|---|---|
| 文生视频（T2VA） | 纯文字 | H3-Base |
| 图生视频（首帧/首尾帧） | 1–2 张图 | H3-Base-FL2VA |
| **参考生视频（Ref2VA / Omni Reference）** | 多模态参考（图+音+视频） | **H3-Base-Ref2VA** |

**铁律**：**参考模式（Ref2VA）和首尾帧（FL2VA）互斥，不能同时用**。本 skill 的角色三视图 + 场景 + 音色场景，走 Ref2VA 就全程参考模式，不混首尾帧。

**模型档位**：H3 吃参考视频；**H3 Max 只支持纯文字或首尾帧**，不支持参考视频。用音色/参考图的项目必须选 H3，不选 H3 Max。

## 三、分辨率与成本（省点数的标准打法）

1. **768P 试稿**（便宜、快、适合多试几版）；
2. 挑满意的**升 2K**（H3 的 2K 是"参照原件重画"，不是简单放大，细节保真）；
3. **先测最短可用时长**，再花点数跑长镜（>10s 的多动作镜每次结果波动大）。

## 四、音色参考的投喂要点

- **音频文件要"说清作用"**：普通参考视频不会因含声音就自动当音色用，必须写清"谁管声音"（对应本 skill 的 `<Audio N>` 定义行）。
- **音色克隆**：传参考音频可克隆说话人音色，用于新写台词的口型同步。
- **音频输入不另收费**（API 口径），但仍是参考文件，受"最多 3 段"限制。

## 五、运镜指令（API 快捷标签）

关键描述后加 `[pan]` / `[zoom]` / `[static]` 这类运镜标签可引导机位运动（API 文档支持）。但本 skill 的正文走"自然英文动作句"写运镜，两者不冲突——标签是 API 快捷方式，正文句子是 Ref2VA 主写法。

## 六、投喂前自检（对照本 skill 机检）

1. 素材代号写法是否匹配当前运行环境（`<Picture N>` vs `@ImageN`）；
2. 是否选了正确 checkpoint（Ref2VA 项目别错选 FL2VA）；
3. 模型是否选了 H3（不是 H3 Max，如果你用了参考图/音色）；
4. 参考文件数是否 ≤ 9 图 + 3 视频 + 3 音频；
5. 分辨率是否先 768P 试稿。
