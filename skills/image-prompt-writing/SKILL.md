# 图像提示词编写（Z-Image t2i / Qwen i2i）

为资产生图工作流编写提示词。本工程文生图走 Z-Image Turbo / Krea2 超写实工作流，图生图走 Qwen-Image-Edit-2511（参考图 + 指令）。

## 一、人物资产：完整设定直出（2026-11-21 定版，替代旧三格写法）

人物是漫剧的脸，**不吸睛没人看**。人物资产不再按「左 1/3 特写 + 右 2/3 三视图」的旧三格拼版写，改成**影视角色四视图设定板**。

### 1.1 版式（四格等宽，写死）

横向宽幅设定板，四格等宽并排，从左至右：

1. **第一格**：面部及肩部近距离特写（突出五官/妆容/发型/皮肤细节）。
2. **第二格**：正面全身站立（完整展示服装正面、身材比例、鞋）。
3. **第三格**：90° 标准侧面全身（展示侧颜、发型轮廓、腰线、服装侧面剪裁）。
4. **第四格**：背面全身（展示后脑发型、服装背部设计、整体比例）。

四格**同一人物**，五官、年龄、发型、服装、鞋、身高、身体比例**完全一致**；不多格不少格；全身人物头脚完整入画不裁切。

### 1.2 背景与光位（写死，别自己改）

- **背景纯白** `#FFFFFF`，无缝、均匀、延伸到画面四边，四格共用一整片连续纯白；**不写浅灰/中性灰**（灰底会把环境色带进 H3，成片人物显脏）。
- **单一柔光**自左上方，四格光位与色温完全一致，电影级质感。

### 1.3 内容三段式（人物设定文本必须覆盖）

按「**面部 → 发型 → 服装 → 气质 → 构图**」写，缺一不可：

1. **面部**：脸型、眉眼、鼻、唇、妆容（裸妆/眼妆/唇妆色号）、皮肤质感。
2. **发型**：发色、长度、卷度、分线、配饰（墨镜/发饰）。
3. **服装**：款式、面料、颜色、剪裁、鞋。
4. **气质**：用词写"温柔/知性/从容/高级感/亲和力"这类**气质词**，但要把气质落成可见事实（眼神、嘴角、站姿、肩颈），不堆抽象词。
5. **构图**：四视图分区（见 1.1）。

### 1.4 两条铁律（必须遵守）

1. **皮肤分男女两档（2026-11-21 实测定版，不要混淆）**：
   - **女性：干净通透、彻底无斑（可做到）**。中文「无斑点」压不住，必须英文强压：`flawless, smooth, even, clear, radiant skin, no freckles, no blemishes, no spots, no dullness`。
   - **男性（中年）：接受自然质感，年龄感优先（彻底无斑做不到）**。Z-Image 对「中年男性」的先验是「成熟=有岁月痕迹=带雀斑晒斑」，且负向通道物理不存在（工作流仅 1 个正向 CLIPTextEncode + ConditioningZeroOut 清零 + cfg=1），所以**纯文本在此到顶**：写「40岁/成熟/灰白发/皱纹」任一词都会触发中年先验连带出斑；不写又默认出 25 岁小年轻。实测三轮二选一无解。**最终口径：男性保留自然皮肤质感（允许轻微纹理/细纹，那是成熟感），用 `clean-shaven, well-groomed, fresh clear skin, smooth even complexion` 兜住"不邋遢、不满脸斑"的底，但**不写 `no age spots / no sun spots / no wrinkles` 这类无效否定词**（否定词根会被当要画的东西，且压不住中年先验）。
   - **年龄写法**：女性可写年龄数字；男性中年角色**不写年龄数字**，改用「成熟稳重、眼神有阅历、气场沉稳」这类气质词定年龄感，避免触发"中年沧桑"先验的同时又显嫩过头。
2. **不刻意像明星/网红**：写"好看、精致、有辨识度、有高级气质"，但**不写"某明星既视感/偶像剧女主脸/网红模板"**——要的是"长得好看的普通人"，不是"像谁"。

### 1.4b 颜值气质基线（男帅女美 + 大气）

人物是漫剧的脸，**漂亮/帅气/大气是硬底线**，LLM 写外观时必须满足，不许写岔：

- **女角色**：漂亮、精致、好看耐看，有主角气场。
- **男角色**：帅气、立体、有型，有辨识度、不油腻。
- **通用「大气」**：神态从容自信、五官轮廓分明、有高级感，**不是小家子气的路人脸/苦相/憔悴脸**。
- **允许素颜/朴素，但脸必须好看**：剧情设定可以让她"穿旧衣、不打扮"，但底子是美人——反差靠"衣服旧、脸好看"撑，不是把脸也写憔悴。
- 气质词要落成可见事实（眼神、嘴角、站姿、肩颈、轮廓），不堆"温柔/知性"这类空词。

### 1.5 否定式一律改正向（Z-Image 负向是死的）

本工程 t2i 的 `negative_prompt` **不生效**（Z-Image roles 无该字段 + 工作流内 ConditioningZeroOut + cfg=1）。所以：

- **不要**写「不要网红脸 / 不要浓妆 / 不要过度磨皮 / 不要文字 / 不要多余人物」这类否定句——词根会被画出来。
- 一律改成**正向事实**：「妆容清透淡雅」「皮肤轻薄真实、自然纹理」「画面里只有这一位人物」。
- 同理「不要字幕/不要边框」= 画字幕/画边框，整句删掉。

### 1.6 权威设定存档规范

用户给的完整角色设定文本，**一字不改存档**到项目 `context/` 下（如 `NN-角色名-anchor.md`），作为该角色的唯一权威锚点；后续分镜/H3 提示词只引用这份锚点的锚点句，不另造描述。唯一允许的改动：背景色按项目统一（纯白）、否定句改正向句。

## 二、场景资产（16:9）

环境氛围、空间透视、光线与风格，画面完整可作背景。

- **大气明亮是硬基线**：构图开阔有层次（前景遮挡 + 中景主体 + 远景纵深）、光线通透不灰暗、色调干净不脏乱；除非剧情明确要压抑/昏暗/悬疑氛围，否则默认明亮通透。
- **风格只进场景图**：项目自定义风格（如「低饱和青绿调、胶片颗粒、霓虹溢色」）**只写进场景图与视频层**，不写进人物图（人物图染色会污染 H3 参考图）。
- 色调/光效要**落到具体名词**，不写「at frame edge / 边缘溢色」这类空间词（会被模型实体化成灯管/边框）——写「magenta bounce on the railing」而非「magenta spill at the frame edge」。

## 三、道具资产（1:1）

纯白背景，画面只出现该道具本身，突出形状/材质/细节；道具自带的文字/标签/包装说明/品牌 logo 要保留并写清内容。

## 四、文字处理（看 style.md 两档）

- **style.md 未限制文字**（默认）：允许保留与主体相关的真实文字（招牌/书名/包装标签/屏幕文案/品牌名/logo），写清内容与位置；不出现与画面无关的字幕条/水印/签名/乱码。
- **style.md 声明禁文字**（视频流水线推荐）：一律回避文字——横幅写「plain unmarked fabric banner」、文件写「blank paper sheet」、屏幕写「lit but blank screen」、招牌写「blank signboard」，不要求保留文字，也不把文字内容写进 prompt。

## 五、prompt 语言与结构

- prompt 用**英文为主**（写实模型对英文响应更好）；角色气质/妆感这类判断词可中英混写，但**皮肤无斑、材质、构图这三处必须英文**。
- 结构化：主体核心特征 → 服装/妆发 → 构图/背景/光位 → 无斑强压句。
- 人物 prompt 不写"视图数量/分格/背景/光位/画质参数"这类系统会注入的字段时，可省略；但**做权威设定直出时**，构图段要完整写（见 1.1）。

## 六、negative_prompt 规则（仅 i2i 生效，t2i 忽略）

> 注意：**本工程 t2i（Z-Image）的 negative_prompt 不生效**，以下负向只对 i2i（Qwen）有意义；t2i 靠正向事实约束。

通用排除：`blurry, low quality, pixelated, distorted, watermark, oversaturated, artificial, plastic-looking`。
人物类额外：`extra fingers, deformed hands, mutated hands, fused fingers, plastic skin, over-smoothed skin`。
人物拼版纠错：`duplicate views, extra poses, cropped head, cut-off feet, inconsistent face, inconsistent clothing, grey backdrop, gray background, colored background, gradient background`。
皮肤无斑（i2i 可加，t2i 用正向）：`freckles, blemishes, acne, age spots, sun spots, dark spots, uneven skin, dull skin, splotchy skin`。

**文字类负向两档（看 style.md）**：
- style.md 未限制文字：**不要**排除 `text, letters, words, logo, signature`。
- style.md 声明禁文字：写 `text, lettering, watermark, logo`（**不写 subtitle/caption/on-screen text**——会诱导模型画字幕条）。

## 七、输出

每个资产输出 JSON：`{"prompt":"...","negative_prompt":"..."}`。

## 八、调用方式

写好后用 `update_asset(id, {prompt, negative_prompt})` 写入资产，再用 `generate_asset_image(asset_id)` 或 `generate_assets_batch` 统一提交（批量优先，避免反复切换工作流导致模型重载）。图生图变体用 `edit_asset_image`。人物换装用 `change_outfit`。若模型支持图片输入，写提示词前先 `view_asset(asset_id)` 看参考图，基于真实图写。
