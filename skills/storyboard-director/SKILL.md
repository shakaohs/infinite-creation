# 文戏分镜 Skill（storyboard-director）

把**剧本原文**（或小说段落）转成**分镜脚本**，再封装成可投喂 Seedance 2.5 / 2.0 的**七段式提示词**。**不写剧本、不做资产锁定、不产出成片**——剧本由用户提供，资产图由用户在外部平台生成（或走 `z-image-prompt-writing` 生图），本 Skill 只做「剧本 → 分镜 → 投喂」这一环。

## 一、能力边界（做什么 / 不做什么）

| 做 | 不做 |
|---|---|
| 剧本原文 → 分镜镜头序列 | 写剧本 / 改剧本台词 |
| 分镜 → 七段式投喂提示词 | 生成图片 / 生成视频 |
| 文戏 / 日常戏分镜 | 打戏（路由到打戏分镜 Skill） |
| 段缝衔接、尾帧锚定、故事板图 | 资产锁定、成片质检、离线看板 |

- **打戏路由**：剧本里出现打斗 / 斗法 / 武打段落时，本 Skill 不处理，标注「打戏段落 → 转打戏分镜 Skill」，文戏镜头照常出。
- **台词零擅删**：上游剧本每一句台词默认**原样进分镜**，无权删改；确需精简只能列「台词精简建议清单」征询用户，确认后才可删。
- **溯源痕迹**：references 内部偶引用的 `sd-script-engine` 等路径为历史溯源（剧本层设定，由用户提供剧本后不再需要），对应规则要点已在正文说明，不影响本 Skill 运行。

## 二、前置锁（无人值守接口 · 锁由调用方传入，不询问）

本 Skill 面向**无人值守流水线**：锁的值由调用方（流水线项目锁卡）在请求里传入，**不询问用户、不弹卡、不停下等待**。缺失时按下表默认值兜底，不阻塞。

| 锁 | 键 | 来源 / 默认 | 说明 |
|---|---|---|---|
| A 模型版本 | `video_model` | 项目锁卡；`seedance25`=2.5 / `seedance20`=2.0 | 两版语法彻底分开、禁混写 |
| B 画幅 | `video_aspect_ratio` | 项目锁卡；16:9 / 9:16 / 21:9 | 全片唯一 |
| C 交付形态 | — | 流水线固定「md 投喂 + 成片」，不出离线看板 | 流水线上下文里不弹此锁 |
| D 段缝衔接 | `seam` | 项目锁卡；auto=按情绪节拍 / tail_frame=尾帧锚定 / hard_cut=换机位硬切 / empty_shot=空镜过渡 | 多段任务判定式不变 |
| I 画风锁 | `style` | 项目锁卡；真人实拍 / 2D 手绘 / 3D CG / 水墨二维 | 影像基底决定机位规则（3D/仿真人禁「特写×平视正面」） |

**素材形态（M 轴，与锁系统正交）**：本 Skill 不持有图。三档——**M0 纯文字锁**（无图号，一致性靠外观档案复述块）/ **M1 编号占位**（图N 槽位 + 素材接线单）/ **M2 已入库**（用户交回图）。流水线里按「当前分镜是否已绑定参考图」自动判 M1/M2，不询问。每次交付首行声明形态。

> **无人值守铁律**：以上锁一律照流水线项目锁卡与项目记录落定；不存在「未指定即停下询问」——缺项用默认值，禁止中断等待用户。

## 三、工作流

1. **接收剧本原文**（用户已有剧本，直接喂入）。
2. **内部分析**（不输出）：场景空间类型 → 情绪节奏 → 人物数量与空间关系 → 权力关系/情绪爆点 → 激进机位机会点 → 机位配比（侧45度默认，常规≤30%）→ **影像基底**（I 锁）→ 表演节拍 → 场景锚点 → 全局色调 → 轴线 → **台词逐句清点**。
3. **设计全部镜头**（连续编号），每镜过八重筛选：场景适配 / 情绪匹配 / 视感配比 / 人物出现策略 / 人物表演 / 镜头经济性 / 衔接（180°轴线/30°规则/景别跳跃/视线匹配/运镜节奏）/ 画面质感。
4. **输出分镜稿**：干净镜头序列，末尾附「台词精简建议清单」（唯一例外输出章节）。
5. **投喂封装**：按 `references/model-adapters.md` 七段式封装为可投喂提示词（见 §六）。

## 四、单镜头模板（九字段，逐镜齐全，缺项写「—」或「无」，禁整行删）

```
### 镜头 XX | {空间类型代号及名称} | {景别} | {焦段} | {机位角度} | {运镜方式} | {人物镜头/非人物镜头}

场景：{场景名}
画面内容：{看图说话，3-6句，覆盖所有关键人物位置与动作；非人物镜头写明"无人物"并说明情绪/信息；情绪靠动作外化不靠形容词；室内说明光源}
状态：{进镜姿态与持物} → {出镜姿态与持物}（无变化写"—"）
光影：{光线方向、光位、光比}
色调：{色调方案名}，高光{色值}，阴影{色值}，色温{数值}K。palette={}/saturation={}/film_stock={}/grain={}/halation={}
台词：{说话人}："{台词}" / 无
重音：{台词里语义最重的字/词}（无台词写"无"）
人声：{台词之外的表演性人声} / 无
音效：{环境音和动作音；音桥标注"音桥入/音桥出"}
```

机位角度 = 方向×高度组合（如 `侧45度+大仰角`）；荷兰角标 `荷兰角{度数}°`。

- **`状态：前→后`**：专拦姿态回退、道具瞬移两类穿帮；发生起身/坐下/拿放/递物/换手/进出画/披挂/受伤/门窗开合必写。
- **`重音：{字/词}`**：每句台词标一个重音字，供特写挂重音句 / 表情峰值对齐 / 配音重读三处取用。
- ⛔ 两栏属分镜层，**投喂封装前剥离**，不进七段式正文。

## 五、高频铁律速查

- 先设计再写；色调定了不改，全片一致（反差色≤15%）。
- 不写「镜头给到」「我们看到」这类元描述，直接描述画面。
- 不计算时长、不自动分段、不写段间总结，镜头连续编号直出。
- 锚点一律中文；方位描述绑定锚点。
- 正反打严守 180° 轴线；同主体相邻镜头机位角度差 ≥30° 或焦段差异显著。
- 相邻镜头过 5 维度自检（轴线/视线/动作重合/道具状态+景别不连续3镜同景别）；运镜 5 模式见 `references/segment-splicing.md`。
- 情绪重锤后必须有留白镜头；重技法只用于重锤瞬间，不超频。
- 常规镜头 30% 左右、侧45度默认、侧面≤15%、大仰俯各≤3次/集、荷兰角每集≤1、手持三级烈度对号入座。
- 表演克制藏七分露三分；站桩说话不超 3s；长镜头全片禁用；长台词必须切镜。
- **每句台词必挂「神态 + 动作」两项**（具体神态 + 具体动作，禁"平静地说""站着说"）。
- **每句台词必标重音字，每个状态变化镜必写状态栏**。
- **台词零擅删**：默认全量承接，精简必须走文末清单 + 征询用户。
- **长对白段必有关系镜**：段内含台词镜 ≥6 时，至少 1 个过肩双人反打。
- 影像基底感知：3D/仿真人脸部特写必须带角度（禁平视正面）；真人守 1/3 配额；2D 同场连用 ≤2。

## 六、投喂封装（七段式）

分镜稿是中间产物，投喂前按 `references/model-adapters.md`（★唯一权威）封装为七段式：

```
【画幅风格】→【场景资产】→【核心人物】→【站位声明】→【时间轴分镜】→【音效】→【强制禁止项】
```

- 分镜层的 `状态` / `重音` 两栏**剥离**，不进七段式。
- 时间轴整数秒口径，禁时间码、禁小数秒。
- 2.5 与 2.0 语法彻底分开：声音字符、Hit-Stop、首尾帧、单段时长（30s/15s）、运镜复杂度均按 `model-adapters.md` 对照表执行。

## 七、故事板图（面板链）

> ★ 唯一权威 = `references/storyboard-sheet-template.md`。

- **每段一张**多面板图，格数 = 该段镜数（4→2×2、6→2×3、9→3×3、12→3×4），禁机械凑九宫格。
- **七态动作相位**：起始/过程/接触/顶点/结果/反应/出口，每格带 5 项（面板ID/动作相位/镜头信息/站位+视线/资产引用）。
- **出口帧 = 下段入口帧**，写全六项（人物/手位/道具状态/光影/轴线/未完成动作）。
- **两版输出**：`CLEAN_GRID` 干净版（无文字，供生图）必出；`TECHNICAL_ANNOTATED` 标注版可选、不进投喂。
- 面板边界 ≠ 剪辑点；干净版不得出现任何文字。
- 可选产出 SHOT_TEXT 分镜线稿卡（俯视走位图 + 逐镜卡，给人看，不进投喂）。
